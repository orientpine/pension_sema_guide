# 퇴직연금·연금계좌 세제혜택 표준 규칙

> **하드코딩 금지 원칙**: 이 스킬의 모든 세율·한도·구조상수는 문서에 숫자로 박지 않는다.
> 각 수치는 `funds/pension_tax_params.json`의 파라미터를 `{id:파라미터ID}` 형태로 참조하며,
> 게이트/런타임에서 그 값으로 치환된다. 시행일은 각 파라미터의 `effectiveDate` 필드를 따른다.
>
> **검증 등급(verificationStatus) 우선**: 각 파라미터의 `verificationStatus`(verified / seed / unverified)를
> 반드시 확인한다. `verified`가 아닌 값에 의존하는 결론은 **"공식 확인 필요, 계산 보류"**로 표기하고
> 확정 세액을 산출하지 않는다(환각 방지).

## 1. 계좌 구조 (Account Types)

세제혜택 연금계좌는 **연금저축 · IRP · DC** 세 갈래이며, 납입 주체와 세액공제 대상 여부가 다르다.

| 계좌 유형 | 취급기관 | 납입 주체 | 세액공제 대상 | 비고 |
|-----------|----------|-----------|:------------:|------|
| **연금저축** | 은행·증권·보험 | 개인 자율납입 | O | 연금저축펀드/신탁/보험 |
| **IRP (개인형퇴직연금)** | 은행·증권·보험 | 개인 추가납입 + 퇴직급여 이전 | **개인 추가납입분만 O** | 이전된 퇴직급여 원금은 공제 대상 아님 |
| **DC (확정기여형·직장)** | 회사 지정 사업자 | 사용자 부담금 + 가입자 추가납입 | **가입자 추가납입분만 O** | 사용자 부담금은 근로소득 단계에서 비과세(별도 세액공제 대상 아님) |

- **핵심 구분**: 사용자(회사)가 내는 DC 부담금은 애초에 과세소득에 잡히지 않으므로 세액공제로 다시 돌려받는 대상이 **아니다**. 세액공제는 **개인이 세후 소득으로 추가납입한 금액**에만 적용된다.
- **총 납입한도(연금저축 + IRP + DC 가입자 추가납입 합산)**: {id:연금_납입한도}원/년

## 2. 납입 단계 (Contribution Stage)

### 2.1 세액공제 한도

| 구분 | 한도 | 근거 |
|------|------|------|
| **연금저축 단독** | {id:연금저축_세액공제한도}원 | 소득세법 §59의3 |
| **연금저축 + 퇴직연금(IRP/DC 추가납입) 합산** | {id:연금계좌_세액공제한도}원 | 소득세법 §59의3 |
| **총급여 기준선 이하 거주자** | {id:연금계좌_세액공제한도_총급여5500이하}원 | 합산 한도는 소득 구간과 무관하게 동일 |

> 세액공제 **한도 금액**은 총급여 수준과 무관하게 동일하다. 총급여 수준은 **공제율(§2.2)**에만 영향을 준다.
> 총급여 기준선의 구체 금액은 별도 파라미터로 미등록 상태이므로, 구간 판정 시 소득세법 §59의3 원문을 확인한다(파라미터명 `연금계좌_세액공제한도_총급여5500이하`가 해당 구간을 지칭).

### 2.2 공제율

| 총급여 구간 | 국세기준 공제율 | 지방세 포함 체감 공제율 |
|-------------|:--------------:|:----------------------:|
| **기준선 초과(고소득)** | {id:공제율_국세기준_고소득}% | {id:공제율_체감_고소득}% |
| **기준선 이하(저소득)** | {id:공제율_국세기준_저소득}% | {id:공제율_체감_저소득}% |

> ⚠️ 체감 공제율({id:공제율_체감_고소득}% / {id:공제율_체감_저소득}%)의 두 파라미터는 `verificationStatus=seed`이다.
> 지방소득세를 더한 체감값은 안내/계산 성격이므로, 확정 절세액 제시 전에 공식 확인이 필요하다.

### 2.3 ISA 만기자금 전환 추가공제

- ISA 만기자금을 연금계좌로 전환하면 **전환금액 × {id:ISA전환_공제율}%**를 세액공제 대상에 추가한다.
- 추가공제 한도: {id:ISA전환_공제한도}원 (조세특례제한법 §91의18).

### 2.4 기여 순서 권장

세후 여유자금의 세제 효율을 극대화하려면 다음 순서를 권장한다.

1. **직장 DC 사용자 부담금**: 근로소득 단계에서 비과세 — 세액공제 한도와 무관하게 우선 확보(공제 한도 소진 대상 아님).
2. **IRP 개인 추가납입**: 합산 세액공제 한도({id:연금계좌_세액공제한도}원) 범위 내에서 공제.
3. **연금저축**: 연금저축 단독 한도({id:연금저축_세액공제한도}원) 및 합산 한도 내에서 공제.

## 3. 운용 단계 (Investment Stage)

- 계좌 내 운용수익(ETF·펀드·채권의 매매차익·분배금·이자)은 **인출 전까지 과세하지 않는다(과세이연)**.
- **과세이연 효과**: 매년 원천징수되던 세금을 인출 시점까지 이연하여 세전 금액으로 재투자 → 복리 효과가 커진다.
- 과세는 **인출 시점**에 연금수령(연금소득세) 또는 연금외수령(기타소득세)으로 이루어진다(§4·§5).

## 4. 수령 단계 (Receipt Stage)

### 4.1 연금수령 개시 요건

- 개시 요건: 만 55세 이상 + 가입 후 5년 경과 <!-- illustrative-date -->
- 예외: 이연퇴직소득만으로 개시하는 경우 등 5년 요건이 완화되는 경우가 있으므로, 구체 사안은 원문 확인.

### 4.2 연금수령한도

연금수령한도는 아래 산식으로 계산한다.

```
연금수령한도 = 평가액 / ({id:연금수령한도_분모상수} - 연금수령연차) × {id:연금수령한도_배수}%
```

- **특이점**: (분모상수 − 연금수령연차) ≤ 0, 즉 **연금수령연차 ≥ {id:연금수령한도_분모상수}**인 경우 → 한도 제한이 없어 전액 수령이 가능하다.
- 한도를 초과해 수령한 금액은 연금소득이 아닌 **연금외수령(기타소득)**으로 과세된다(§5).

### 4.3 인출순서 (소득세법 시행령 §40의3)

계좌에서 인출되는 재원은 다음 순서로 인출된 것으로 본다.

1. **① 이연퇴직소득** (퇴직급여 원천) — 퇴직소득세 기준 과세(§4.5).
2. **② 과세제외 금액** — 세액공제를 받지 않은 납입액(과세된 적 있는 원금) → 인출 시 과세 없음.
3. **③ 세액공제 받은 납입액 + 운용수익** — 연금수령 시 연금소득세(§4.4) 과세 대상.

### 4.4 연금소득세율 (지방세 포함, **미검증**)

| 수령 연령 | 세율 |
|-----------|:----:|
| 70세 미만 | {id:연금소득세율_70세미만}% |
| 70세 이상 80세 미만 | {id:연금소득세율_70세이상80세미만}% |
| 80세 이상 | {id:연금소득세율_80세이상}% |

> ⚠️ 세 파라미터 모두 `verificationStatus=unverified`(law.go.kr 직접 앵커 미확인)이다.
> 적용 전 소득세법 §20의3 원문으로 세율·연령구간을 확인하고, 그 전까지 확정 세액 산출은 보류한다.

### 4.5 이연퇴직소득의 퇴직소득세 (인출순서 ①, **미검증**)

이연퇴직소득을 연금으로 수령할 때 적용되는 **퇴직소득세 대비 원천징수 비율**은 연금수령 기간에 따라 달라진다.

| 연금수령 기간 | 파라미터 |
|---------------|:--------:|
| 10년 이하 | {id:퇴직소득세_감면율_10년이하}% |
| 11년 ~ 20년 | {id:퇴직소득세_감면율_11년_20년}% |
| 21년 이상 | {id:퇴직소득세_감면율_21년이상}% |

> ⚠️ 세 파라미터 모두 `unverified`이다. 또한 파라미터명은 "감면율"이나 근거 자료는 "퇴직소득세의 X% 수준으로 원천징수(부과 수준)"로 기술되어 **감면/부과 방향 해석에 주의**가 필요하다.
> 소득세법 §22 원문으로 비율의 의미(부과 vs 감면)와 구간을 확인한 뒤에만 계산한다.

## 5. 중도해지·중도인출 (Early Withdrawal)

- **중도해지**: 세액공제를 받은 납입액과 운용수익에 대해 **기타소득세(지방소득세 포함)**가 부과된다.
  - 기타소득세율은 `pension_tax_params.json`에 **미등록 파라미터**이다(별도 법정 세율). 하드코딩하지 말고, 적용 시 소득세법 상 기타소득세율을 공식 확인한다.
  - 참고: 국세 기준 세율에 지방소득세를 더해 체감 세율을 산정하는 gross-up 구조는 공제율 체감 파라미터(`공제율_체감_고소득`/`공제율_체감_저소득`)의 산정 원리와 동일하다(값 등치가 아니라 방식만 참고).
- **부득이한 사유**(천재지변, 3개월 이상 요양, 파산·개인회생, 가입자 사망·해외이주 등)에 해당하면 → 중도인출분을 **기타소득세가 아닌 연금소득세(저율)**로 과세한다.
- 만 55세 이후라도 **연금수령한도 초과분·연금외수령**은 기타소득세 대상이다(§4.2).

## 6. 종합소득세 vs 분리과세 선택

- **분리과세 선택 가능**: 연 사적연금소득 합계가 {id:사적연금_분리과세_경계}원 **이하(포함, ≤)**이면 분리과세(원천징수 종결)를 선택할 수 있다.
- **종합과세**: 사적연금소득이 {id:사적연금_분리과세_경계}원을 **초과**하면 다른 종합소득과 합산하여 종합소득세율로 신고한다.
- **선택 기준**: 종합합산 시의 실효세율과 연금소득 분리과세율({id:연금소득세율_70세미만}% 등, **미검증**)을 비교해 유리한 방식을 택한다.
  - 연금소득세율 파라미터가 `unverified`이므로, 확정 비교 계산은 §4.4의 원문 확인 이후로 보류한다.

## 7. 건강보험료 영향

- **피부양자 자격**: 연간 소득 합산이 피부양자 소득요건을 초과하면 피부양자 자격에서 탈락할 위험이 있다. 사적연금 수령액이 소득 합산에 포함되는지는 제도 개정이 잦으므로 **국민건강보험공단 최신 기준**을 확인한다.
- **지역가입자 전환**: 피부양자 탈락 시 지역가입자로 전환되며, 소득·재산 기반 보험료가 부과되어 부담이 늘 수 있다.
- 구체적 소득요건 금액은 파라미터로 관리하지 않으므로(건보 소관), 본 스킬에서 숫자로 단정하지 않는다.

## 8. 흔한 함정 (Common Pitfalls)

| 함정 | 결과 | 예방책 |
|------|------|--------|
| DC → IRP 자동 이전 시 세액공제 중복 착각 | 한도 초과·과다공제 신고 위험 | 세액공제는 합산 한도({id:연금계좌_세액공제한도}원) 기준 **1회만** 적용됨을 확인 |
| 연금수령한도 초과 수령 | 초과분에 **기타소득세** 과세 | 수령 전 §4.2 산식으로 한도 검산 |
| 분리과세 경계 계산 시 타 사적연금 누락 | 경계 오판 → 종합과세 대상 누락 | {id:사적연금_분리과세_경계}원은 **전 계좌 사적연금 합산** 기준으로 계산 |
| 미검증 파라미터로 확정 세액 제시 | 잘못된 세액(환각) | `verificationStatus≠verified`(seed/unverified) 값 의존 결론은 **"공식 확인 필요, 계산 보류"**로 표기 |

## 9. 계산식 스펙 (Calculation Formulas)

> **절대 규칙**: 아래 모든 수치·상수는 반드시 `{id:parameter_id}` 참조만 허용합니다.  
> 리터럴 숫자·금액·세율·배수·구조상수를 프롬프트·테스트에 직접 쓰는 것은 **금지**입니다.

### 9.1 계산 보류 규칙 (CRITICAL)

다음 중 하나라도 해당하면 해당 `parameter_id` 의존 계산은 **즉시 보류**합니다:
- `verificationStatus` ≠ `verified` (seed / unverified / needs_review / proposed)
- `effectiveDate` > 오늘 날짜 (미래 시행 파라미터)
- `refreshStatus` = `disproven` (법령 변경 감지)

계산 보류 시 반환: `"공식 확인 필요, 계산 보류 — [파라미터 id] 미검증"`

### 9.2 세액공제 계산

```
세액공제액 = min(공제대상납입, {id:연금계좌_세액공제한도}) × {id:공제율_국세기준_고소득}  (총급여 기준선 초과)
세액공제액 = min(공제대상납입, {id:연금계좌_세액공제한도_총급여5500이하}) × {id:공제율_국세기준_저소득}  (총급여 기준선 이하)
```

체감세율(지방세 포함) 사용 시:
```
세액공제액(체감) = min(공제대상납입, {id:연금계좌_세액공제한도}) × {id:공제율_체감_고소득}  (총급여 기준선 초과)
세액공제액(체감) = min(공제대상납입, {id:연금계좌_세액공제한도_총급여5500이하}) × {id:공제율_체감_저소득}  (총급여 기준선 이하)
```

**basis 표기 필수**: 반드시 **국세기준** / **지방세포함** 라벨을 구분해 명시합니다.  
`{id:공제율_체감_고소득}` / `{id:공제율_체감_저소득}`은 `verificationStatus=seed`이므로 계산 결과는 **공식 확인 필요, 계산 보류 또는 참고용**입니다.

### 9.3 ISA 추가 세액공제

```
ISA추가공제대상 = min(ISA전환액 × {id:ISA전환_공제율}, {id:ISA전환_공제한도})
ISA추가세액공제액 = ISA추가공제대상 × 적용공제율
```

적용공제율은 총급여 기준선 판정에 따라 §9.2의 국세기준 공제율 또는 지방세포함 체감 공제율 중 명시한 basis와 일치하는 파라미터를 선택합니다.

### 9.4 연금수령한도 (Pension Withdrawal Limit)

```
연금수령한도 = 연금계좌_평가액 / ({id:연금수령한도_분모상수} - 연금수령연차) × {id:연금수령한도_배수}
```

**특이점 처리** (CRITICAL):
- `({id:연금수령한도_분모상수} - 연금수령연차)` ≤ 영  
  → 즉, 연금수령연차 ≥ `{id:연금수령한도_분모상수}` 이면  
  → **한도 제한 없음 / 전액 수령 가능**

반올림: **원 단위 절사** (소수점 이하 버림)

### 9.5 퇴직소득세 감면 (연금 전환 수령 시)

인출순서 §40의3 ①에 따른 이연퇴직소득에 적용합니다. 각 구간은 파라미터명의 기간 구간을 그대로 따르며, 구간 수치 자체를 본문에 하드코딩하지 않습니다.

```
퇴직연금 수령 세액 = 이연퇴직소득세 × (전액비율 - {id:퇴직소득세_감면율_10년이하})
퇴직연금 수령 세액 = 이연퇴직소득세 × (전액비율 - {id:퇴직소득세_감면율_11년_20년})
퇴직연금 수령 세액 = 이연퇴직소득세 × (전액비율 - {id:퇴직소득세_감면율_21년이상})
```

⚠️ 위 감면율은 `verificationStatus=unverified` — 계산 결과는 **공식 확인 필요, 계산 보류**. 세무사 확인 필수.

### 9.6 분리과세 vs 종합과세 비교

분리과세 경계: 사적연금소득 합계 ≤ `{id:사적연금_분리과세_경계}` (이하 포함, inclusive)

```
분리과세 적용 여부: 연간 사적연금소득 합계 ≤ {id:사적연금_분리과세_경계}
  → 분리과세 선택 가능: 적용 연령구간별 {id:연금소득세율_70세미만} / {id:연금소득세율_70세이상80세미만} / {id:연금소득세율_80세이상} (지방세포함, unverified)
  → 종합과세: 실효 종합세율과 비교 후 유리한 방식 선택

종합과세: 연간 사적연금소득 합계 > {id:사적연금_분리과세_경계}
  → 종합소득 합산 필수
```

⚠️ 연금소득세율은 `verificationStatus=unverified` — 계산 결과는 **공식 확인 필요, 계산 보류**. 세무사 확인 필수.

### 9.7 반올림 규칙
