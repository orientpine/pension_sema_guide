# 절세 전략 플랜 (익명 골든 샘플)

> `tax-strategy-planner` 에이전트의 **익명 예시 출력**. 세법 수치는 `parameter_id`로만 인용하고,
> 재계산은 `tax-calc-verifier`(02)가 python3로 독립 검증합니다. 개인정보는 포함하지 않습니다.

## 익명 투자자 프로필

| 항목 | 값 |
|------|-----|
| 총급여 | 6,000만원 (고소득 → 국세기준 공제율 [id:공제율_국세기준_고소득]) |
| 나이 | 45세 |
| 은퇴 예정 | 65세 (약 20년 후) |
| IRP 납입 | 연 600만원 |
| 연금저축 납입 | 연 300만원 |
| DC 직장 | 별도 (세액공제 대상 아님) |
| ISA 전환 | 없음 |
| 연금수령 연차 | 없음 (납입 단계) |

## 1. 납입 최적화 — 세액공제 한도 100% 활용

- 연간 IRP 600만원 + 연금저축 300만원 = 합산 [id:연금계좌_세액공제한도]원 → 세액공제 한도 **100% 활용**
- 세액공제액 (국세기준 [id:공제율_국세기준_고소득]):
  - [id:연금계좌_세액공제한도]원 × [id:공제율_국세기준_고소득] = **1,080,000원** (원 단위 절사)
- 연간 총 납입한도 [id:연금_납입한도]원 이내이므로 추가 납입 여력이 있으나, 세액공제 한도([id:연금계좌_세액공제한도]원)를 초과하는 납입분은 공제 대상이 아님에 유의.

> 근거: 소득세법 §59의3 제1항 / 소득세법 시행령 §40의2 제1항
> 검증: `02-calc-verify` (python3 재계산 = 1,080,000원, PASS)

---

## 2. 운용 — 과세이연 복리 유지

- 납입액은 인출 전까지 과세이연되어 복리 성장. 20년 장기(45→65세) 투자에 유리.
- 저비용 인덱스 중심 운용으로 총보수를 낮추는 것이 세제 혜택과 함께 복리 효과를 극대화. (개별 수익 수치는 개인별 시뮬레이션 필요 — 본 플랜은 개념 권고)

## 3. 수령 설계 (사전 점검)

- 은퇴 후 사적연금 연 수령액을 [id:사적연금_분리과세_경계]원 이하로 설계하면 저율 분리과세 선택 가능.
- 예시(참고): 잔고 5,000만원·연금수령 3년차의 연금수령한도
  - floor(5,000만원 / ([id:연금수령한도_분모상수] − 3) × [id:연금수령한도_배수]) = **7,500,000원**
  - (본 투자자는 납입 단계라 즉시 적용 대상 아님 — 실제 수령 시점 재계산 필요)
- 연금소득세율([id:연금소득세율_70세미만] 등)·퇴직소득세 감면율([id:퇴직소득세_감면율_11년_20년] 등)은 `unverified` → **공식 확인 전 계산 보류**.

> 근거: 소득세법 §14 제3항·§20의3 / 소득세법 시행령 §40의2 제2항
