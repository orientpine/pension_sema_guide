## 2. 재계산 상세 (formula)

### 2.1 연간 세액공제
- 산식: `floor(min(납입합산, 연금계좌_세액공제한도) × 공제율_국세기준_고소득 / 100)`
- 대입: `min(9,000,000, 9,000,000) × 12% = 1,080,000원`
- 판정: report 1,080,000 == computed 1,080,000 → **PASS** (diff 0)

### 2.2 분리과세 경계 판정
- 산식: `연간 사적연금소득 ≤ 사적연금_분리과세_경계 → 분리과세 available`
- 대입: 경계값 15,000,000원 검증. 납입 단계이므로 현재 수령소득 0 → available
- 판정: **PASS**

### 2.3 연금수령한도 (예시 시나리오)
- 산식: `floor(잔고 / (연금수령한도_분모상수 − 연차) × 연금수령한도_배수 / 100)`
- 대입: `floor(50,000,000 / (11 − 3) × 120%) = 7,500,000원`
- 판정: **PASS** (예시 — 투자자는 납입 단계라 실제 적용 아님)
